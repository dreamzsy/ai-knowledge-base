# 技术内容深度分析技能

读取已采集的技术原始数据，对每条做深度分析（摘要、技术亮点、评分、标签建议），
并提炼整体趋势，输出结构化 JSON 分析结果，供后续整理与分发。

## 使用场景

- 已有 `knowledge/raw/` 原始采集数据，需要做内容理解与价值判断时。
- 需要为一批技术项目生成摘要、技术亮点、价值评分时。
- 需要从一批项目中发现共同主题、新兴概念等趋势信号时。

## 执行步骤

1. **读取最新采集文件**：在 `knowledge/raw/` 中定位**最新**的采集文件
   （如 `github-trending-YYYY-MM-DD.json`），读取其 `items` 数组作为分析输入。
2. **逐条深度分析**：对每个项目产出——
   - **摘要**（`summary`）：中文，**≤ 50 字**，讲清是什么、解决什么问题。
   - **技术亮点**（`highlights`）：**2–3 个**，用事实说话（具体能力 / 指标 / 设计），
     不空泛、不堆营销词。
   - **评分**（`score`）：**1–10 整数**，并附 `score_reason`（一句话理由），
     按下方「评分标准」执行。
   - **标签建议**（`tags`）：给出受控词表角度的建议标签（如 LLM / Agent / RAG /
     MCP / Framework 等）。
3. **趋势发现**：横向比较全部项目，提炼**共同主题**（多个项目共享的方向）与
   **新概念**（新出现或快速升温的技术名词），形成趋势洞察。
4. **输出分析结果 JSON**：将逐条分析 + 趋势洞察组织为结构化 JSON 返回，
   结构见下方「输出格式」。

## 评分标准（score，1–10 整数）

- **9–10　改变格局**：范式级 / 可能重塑方向，必看。
- **7–8 　直接有帮助**：能直接用于当前工作或决策。
- **5–6 　值得了解**：有信息增量，知道即可。
- **1–4 　可略过**：噪音、重复或无关，可忽略。

## 注意事项

- **只分析、不落盘最终条目**：本技能产出分析结果，入库由 organizer 负责。
- **不改写原始数据**：在 raw 事实字段之上**附加**分析字段，不修改 title / url /
  stars 等客观事实。
- **不臆造**：摘要与亮点须基于真实内容（必要时 WebFetch 打开 `url` 核实），
  拿不到的填 `null`，绝不编造指标或链接。
- **评分约束（硬性）**：单批 **15 个项目中，9–10 分不超过 2 个**——高分是稀缺信号，
  不为"看起来热门"而拔高，严格对应评分标准。
- **摘要克制**：`summary` 严格 ≤ 50 字；`highlights` 控制在 2–3 个。
- **语言**：分析字段统一用中文。

## 输出格式

```json
{
  "skill": "tech-summary",
  "analyzed_at": "2026-06-10T09:00:00+08:00",
  "source_file": "knowledge/raw/github-trending-2026-06-10.json",
  "items": [
    {
      "name": "owner/repo",
      "url": "https://github.com/owner/repo",
      "summary": "≤50 字中文摘要：是什么、解决什么问题。",
      "highlights": ["亮点1（用事实说话）", "亮点2"],
      "score": 8,
      "score_reason": "一句话说明为何给此分（对应评分标准）。",
      "tags": ["LLM", "Agent"]
    }
  ],
  "trends": {
    "common_themes": ["多个项目共享的主题方向"],
    "new_concepts": ["新出现或快速升温的技术概念"]
  }
}
```

字段说明：
- `skill`：固定 `tech-summary`，标记产出来源技能。
- `analyzed_at`：分析时刻，ISO8601 带时区。
- `source_file`：本次分析所读取的 raw 文件路径。
- `items`：逐条分析数组，每条含 `name` / `url` / `summary`（≤50 字）/
  `highlights`（2–3 个）/ `score`（1–10）/ `score_reason` / `tags`。
- `trends`：趋势洞察，含 `common_themes`（共同主题）与 `new_concepts`（新概念）。
